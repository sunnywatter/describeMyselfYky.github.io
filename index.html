摘要

我相信代码能创造真实价值。把抽象想法转化为具体方案，是我最享受的过程。学习—实践—复盘的循环，让我保持长期主义与自驱力。

一、技术深耕：全栈开发与系统架构

后端聚焦 Spring Boot 与 REST 设计，关注可扩展与性能；积累了数据库优化、缓存策略、分布式设计经验。

前端熟练运用 Vue 3 组合式 API，重视交互与一致性体验，形成前后端分离的完整知识体系；参与算法竞赛（如 CCPC），锻炼严谨与解题能力。

二、项目实践：从概念到产品

独立完成两款小程序：即时通讯（云开发）与第三方 API 智能服务。从需求到上线，完成技术选型、性能优化与用户反馈迭代。

带队完成省级创创项目，负责架构与推进，取得 2 项软著，沉淀工程协作与风险把控能力。

三、技术社区与持续成长

创立校内算法社团，组织分享与维护管理小程序；坚持写博客，系统化沉淀项目经验与技术思考。

四、职业愿景与价值追求

期望加入重视创新与卓越的团队，用全栈能力与架构思维解决真实问题。持续精进，以人文关怀与商业意识构建可靠的工程价值。
