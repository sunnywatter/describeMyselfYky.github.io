个人网站

一个简洁现代的单页作品集，包含首页（英雄区）、关于我、作品集、博客与联系模块。纯 HTML/CSS/JS，无需构建工具。

开始使用

- 双击 `index.html` 在浏览器打开。
- 将你的头像放在 `assets/images/avatar.jpg`。
- 将简历 PDF 放在 `assets/docs/resume.pdf` 并更新页面链接。
- 在 `index.html` 中替换文案（如大标题、技能、项目等）。
- 在联系区替换邮箱与社交链接。

自定义

- 颜色、排版等全局样式在 `assets/css/styles.css`。
- 动效与交互（筛选、模态框、平滑滚动）在 `assets/js/main.js`。

目录结构

```
.
├─ index.html
└─ assets
   ├─ css
   │  └─ styles.css
   ├─ js
   │  └─ main.js
   ├─ images
   │  └─ avatar.jpg (自行添加)
   └─ docs
      └─ resume.pdf (自行添加)
```

许可

个人自由使用与修改。
